HTML-Feedbacker

Text direkt anpassen & Design-Wünsche notieren – auf jeder Webseite, auch lokal auf deinem Mac

1 Einmalig einrichten

Ziehe diesen Button in deine Lesezeichenleiste (nicht klicken):
🪲 HTML-Feedbacker

Wenn die Lesezeichenleiste nicht sichtbar ist: Cmd + Shift + B

Klappt das Ziehen nicht?
  1. Klicke auf Code kopieren unten
  2. Rechtsklick auf deine Lesezeichenleiste → Lesezeichen hinzufügen
  3. Bei Name: HTML-Feedbacker
  4. Bei URL: tippe erst javascript: von Hand ein (klein geschrieben, kein Leerzeichen danach) und füge direkt dahinter mit Cmd + V den kopierten Code ein
  5. Speichern

Der Umweg über das Selbst-Eintippen von javascript: ist nötig, weil Chrome und Brave aus Sicherheitsgründen verhindern, dass man diesen Teil direkt einfügt.

2 So benutzt du es

  1. Öffne die Seite, die du bearbeiten willst – egal ob eine lokale HTML-Datei, deine eigene Landingpage oder eine fremde Webseite als Inspiration
  2. Klicke auf das Lesezeichen 🪲 HTML-Feedbacker – unten rechts erscheint eine kleine Werkzeugleiste
  3. Wähle einen der zwei Modi (siehe unten)
  4. Wenn du fertig bist: Klick auf Kopieren – alle Notizen landen als fertiger Text in deiner Zwischenablage
  5. Füge den Text einfach in den Chat mit Claude ein
✏️ Text-Modus

Klick auf einen Text macht ihn direkt beschreibbar. Du tippst die Änderung, siehst sofort live, wie sich die Seite verhält.

🖱️ Element-Modus

Klick auf ein Element (Button, Bild, Box) öffnet ein Notizfeld, z. B. "größer machen" oder "mehr Abstand".

Wichtig zu wissen

✓ Die Text-Bearbeitung im Browser ändert nur die Anzeige, nicht die echte Datei. Die eigentliche Änderung übernimmt Claude, sobald du das kopierte Feedback einfügst.

✓ Auf fremden Webseiten funktioniert nur der Element-Modus sinnvoll (zum Notieren von Inspiration, z. B. "so einen Block will ich auch, in meinen Farben") – die Datei gehört dir dort ja nicht.

✓ Mit 📋 siehst du jederzeit die Liste deiner bisherigen Notizen, mit × kannst du einzelne wieder löschen.

✓ Mit ✕ schließt du das Werkzeug komplett und setzt alles zurück.
